### 👨‍💻 Tentang Saya

* 🔭 **Saat ini sedang fokus pada**: Pengembanan aplikasi web skala besar, **PWA (Progressive Web App)**, dan sistem informasi manajemen berbasis real-time.
* 🚀 **Keahlian Utama**: Modern React ecosystem (React 19, Vite, Next.js), TypeScript, Tailwind CSS v4, Supabase (PostgreSQL), & REST/GraphQL API.
* 💡 **Prinsip Engineering**: Mengutamakan performa tinggi (0ms lag, optimasi bundle), keindahan antarmuka (UX/UI modern), serta kebersihan kode (*Clean Code & Security First*).
* 🎯 **Tujuan**: Membangun solusi digital yang berdampak nyata dan mempermudah operasional organisasi/lembaga.
